# Portfolio Website

Personal portfolio site for Muhammad Nafis Hibatullah, built with Next.js and Tailwind CSS, and exported as a fully static site.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build

```bash
npm run build
```

This generates a static export in the `out/` directory, ready to be served from any static host.

## Deployment

The site is deployed to GitHub Pages via the workflow in `.github/workflows/deploy.yml`, which builds and publishes the site automatically on every push to `main`.
